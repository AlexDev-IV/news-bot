# Асинхронный Telegram-бот для парсинга Hacker News

Асинхронный Python-бот, который мониторит главную страницу Hacker News, собирает свежие заголовки статей и отправляет их в Telegram-канал. Проект полностью упакован в Docker-контейнер и управляется через современный менеджер зависимостей Poetry.

## ✨ Особенности проекта
* **100% Асинхронность:** Написан на `aiogram 3.x` и `aiohttp`, не блокирует поток при сетевых запросах к сайту и API Telegram.
* **Контейнеризация (Docker):** Полностью изолированное Linux-окружение для легкого деплоя на любой сервер одной командой.
* **Современный стек Python:** Использование стандартов PEP 621 и менеджера пакетов `Poetry` для строгого контроля зависимостей.
* **Фильтрация дубликатов:** Встроенная база данных `SQLite` (`aiosqlite`) гарантирует, что пользователи не получат одну и ту же новость дважды.
* **Безопасность (12-Factor App):** Все конфигурации и токены вынесены в переменные окружения (`.env`), исключая утечку секретов в репозиторий.

## 🛠 Технологический стек
* Python 3.11
* Aiogram 3.x (Telegram Bot API)
* Beautiful Soup 4 + lxml (Парсинг HTML)
* Aiohttp (Асинхронные HTTP-запросы)
* Aiosqlite (Асинхронная работа с базой данных)
* Poetry (Управление проектом и пакетами)
* Docker & WSL (Контейнеризация и среда выполнения)
